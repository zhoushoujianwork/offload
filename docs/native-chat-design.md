# Native chat

The macOS app gets a native chat window. The user states a goal, offload runs it, and the app shows the answer.

- **New Chat:** the user describes a goal and starts a new conversation.
- **Continue:** the user sends a follow-up in an existing conversation, which resumes its session.
- **Rich Markdown:** answers are shown as formatted Markdown.
- **Final answer plus live activity:** the final answer arrives when the run ends. While it runs, the window shows live activity.
- **Default read-only:** a chat is read-only unless the user chooses otherwise.
- **Workspace:** a chat uses a general workspace or a workspace the user selects.

API and cancellation details: [native-chat-design-detail.md](native-chat-design-detail.md).
